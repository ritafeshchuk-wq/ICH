# ИЧ — исполнительный чертёж по съёмке

Программа строит ИЧ по съёмке: для телефонной канализации — план с колодцами, пролётами и футлярами, профиль с таблицей и ведомость колодцев; для кабеля наружного освещения — план с опорами и ведомость участков; для закрытого перехода ГНБ — профиль, план, сечения, штамп, каталог и протокол бурения. Сверяет съёмку с проектом, может подогнать чертёж под проект с заданным допуском и выдаёт список расхождений.

**Запуск:** https://ritafeshchuk-wq.github.io/ICH/

Программа работает в браузере, ничего устанавливать не нужно. Файлы обрабатываются на вашем компьютере и никуда не отправляются. Скачанный `index.html` тоже работает без интернета.

## Какие сети

Сеть определяется по кодам «Абриса» автоматически, список найденных сетей — слева.

| Сеть | Коды | Что строится |
|---|---|---|
| Телефонная канализация | 476, 478, 4028, 47, 99 | план, профиль, ведомость колодцев, сверка с проектом |
| Закрытый переход ГНБ | 4028 с глубиной в номере («2-1.36») | профиль с таблицей (земля, верх трубы, глубина, расстояния, уклоны, длины, материал, покрытие, пересечения), план с длинами, сечения 1-1 и 2-2 с кабелями, штамп, каталог (№, X, Y, H) и протокол бурения в Excel |
| Кабель НО / ЭС | 491, 65, 4028 | план с опорами, трубами и футлярами, отметки труб, ведомость участков от опоры до опоры, итоги по составу |
| Кабельная канализация, кабельная линия, водопровод, теплосеть, канализация, газопровод, водосток | 4026, 4021, 4041…, 4071…, 4051…, 4061…, 4091… | распознаются; ИЧ добавляется по образцам |

Ситуация (коды на 7…) в ИЧ не входит. Если в съёмке несколько сетей, нужную выбирают слева.

## Что нужно для ИЧ

Этот список висит на стартовом экране программы и свёрнутым блоком слева во время работы — с отметками, что уже открыто, а чего не хватает.

| Файл | Зачем | Обязательно |
|---|---|---|
| Съёмка (DXF с `_block2`, `.are`, `.pco`) | точки сети | да |
| **Геоподоснова МГГТ (DXF)** | на ИЧ ложится окно геоподосновы вокруг сети (±40 м, меняется) — на исходных слоях и цветах, с блоками и подписями | **да — без неё DXF ИЧ не выдаётся** |
| Проект (PDF) | вкладка «Проект»: лист проекта рядом с ИЧ для сверки | нет |
| Спецификация проекта (строки таблицы или DXF проекта) | материал, SDR и ГОСТ труб, марки кабелей берутся в ИЧ; сверка ИЧ со спецификацией | нет |

DWG программа не читает — сохраните чертёж в AutoCAD как DXF. Спецификация в PDF проекта обычно нарисована линиями (без текста), поэтому её строки вставляют вручную или берут из DXF проекта.

## Как пользоваться

1. **Откройте съёмку** — кнопкой или перетащите файл в окно. Подходит DXF с блоками точек `_block2` (из «Абриса» или после расстановки блоков) и полевые файлы `.are` / `.pco`.
2. **Заполните проект** справа: «Заполнить строки по съёмке» создаёт строки под каждый колодец и пролёт. Впишите имена и проектные значения или вставьте столбцы из Excel (встаньте в ячейку и нажмите Ctrl+V). Проект сохраняется в браузере сам; кнопкой «Сохранить проект» его можно забрать файлом и потом открыть на другом компьютере.
3. **Выберите режим:** «по факту» или «под проект» с допуском в сантиметрах (5, 10, 30, 60 или своё число). Профиль можно выключить.
4. **Проверьте** вкладки «План», «Профиль», «Ведомость» и «Сверка с проектом».
5. **Скачайте** ИЧ в DXF (AutoCAD 2000) и расхождения в CSV (открывается в Excel).

Кнопка «Пример» открывает условную съёмку с проектом — чтобы посмотреть, как всё работает.

## Коды точек

| Код | Доп. код | Что это |
|---|---|---|
| 476 | `_kks-2`, `_kks-3`, `_2,99x1,60` | обечайка, центр колодца; тип или размер камеры |
| 47 | `_np` / `_vp` | низ / верх плиты |
| 99 | — | дно колодца |
| 478 | `_1d110`, `_24d125` | верх трубы; число и диаметр труб |
| 4028 | `_1d325` | верх футляра; участок — футляр, если оба конца 4028 |
| 4028 / 4028.. | номер `2-1.36` | ГНБ: земля над трубой и глубина локатора до оси трубы; точка без глубины — верх трубы в приямке |

Связи: `..` — с предыдущей точкой, `..N` — с точкой N, `..,N` — с предыдущей и с N. Трубы должны начинаться и заканчиваться у колодцев (ближе 2 м от обечайки).

## Что считает программа

- Длина пролёта — от центра до центра колодца.
- Глубина колодца = обечайка − дно; Нг. = обечайка − низ плиты; высота камеры = низ плиты − дно.
- Верх трубы в футляре: одна труба лежит на дне футляра.
- Профиль: 1:500 по горизонтали, 1:100 по вертикали.
- Колодцы проекта сопоставляются со съёмкой по порядку вдоль трассы; направление хода выбирается по лучшему совпадению отметок (или задаётся вручную — «Начало хода»).
- В режиме «под проект» значения с расхождением не больше допуска берутся из проекта, остальные — по съёмке. Подгоняются обечайки, дно, горловина, верх трубы на входе и выходе, длины пролётов и футляров. План и промежуточные точки трубы остаются по съёмке.

## ГНБ (закрытый переход)

Обучено по принятым МГГТ ИЧ 2692а-26 (ГНБ 6) и 3118а-26 (ГНБ 2), ТПУ «Домодедовская».

- Переход — цепочка точек 4028: точка без «..» начинает новый переход, «..» продолжает. Если переходов несколько, нужный выбирают слева.
- Нумерация точек — с запада (слева на профиле), как в принятых ИЧ; можно развернуть.
- Верх трубы = земля − глубина локатора + поправка (половина d, округлённая вниз до см: для d110 — 0,05 м).
- Земля у приямков: введённая вручную, иначе ближайшая точка ситуации (7…) в 6 м, если труба под ней не мельче приямка, иначе верх трубы + 0,70 м.
- Глубина и уклоны считаются от округлённых отметок; длины перехода — суммы того, что написано в таблице (расстояния до 0,1 м, длины до 0,01 м).
- Профиль 1:100 по обеим осям на листе 1:500 (×5), текст 1,5 — как на образцах, его можно вставить в лист с геоподосновой.
- Протокол бурения: штанги (3,05 м) по плану от т.1, их число — по длине по профилю; уклон, % — на длине штанги, глубина, см — до оси трубы на её конце.

## Чего пока нет

Ответвления трассы, развёртки колодцев, линия земли и пересечения с коммуникациями для телефонной канализации (нужна геоподоснова), рамка и штамп для ТК и НО, ситуационный план и подложка геоподосновы, чтение проекта прямо из ИД (проектные профили ГНБ в PDF — кривые без текста). Оформление доводится по образцам принятых ИЧ.

## Для разработки

- `src/` — исходники: `ich.js` (расчёт и запись DXF), `gnb.js` (закрытый переход ГНБ), `geo.js` (геоподоснова и спецификация), `ui.js` (интерфейс), `style.css`, `dxf-skeleton.json` (заготовка DXF AutoCAD 2000, как в «Абрисе»).
- `python3 build.py` собирает из них `index.html` — его и открывает GitHub Pages.
- `python/` — прежняя версия для командной строки (нужен шаблон DXF, см. `python3 python/ich.py -h`).
