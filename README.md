# ICH — исполнительный чертёж телефонной канализации по съёмке

Программа строит ИЧ (план, профиль с таблицей-подвалом, ведомость колодцев) по съёмочному DXF с блоками `_block2`, сверяет его с проектом и пишет список расхождений.

Статус: **прототип**. Оформление упрощено и доводится по образцам принятых ИЧ.

## Что нужно

- Python 3.8+ (только стандартная библиотека; для `preview.py` — `matplotlib`).
- **Шаблон DXF** — любой чертёж AutoCAD 2018 (AC1032), сохранённый как текстовый DXF. Из него берутся слои, стили и настройки; объекты модели удаляются. Укажите его через `--template`, переменную `ICH_TEMPLATE` или положите `template.dxf` рядом с `ich.py`.
- **Съёмка** — DXF с блоками `_block2` (атрибуты `№`, `H`, `TXT`), коды точек по «Абрису».
- **Проект** (необязательно) — JSON с колодцами и пролётами, см. `examples/project.example.json`.

## Запуск

```
python3 ich.py съёмка.dxf ИЧ.dxf --template шаблон.dxf --project проект.json
```

Без `--fit` и `--profile` программа спросит:

- «Подправить ИЧ под проект? [д/н]» и «До какого расхождения подгонять, см».
- «Строить профиль? [д/н]».

Те же ответы можно задать сразу:

| Параметр | Значение |
|---|---|
| `--fit 10` | подогнать под проект всё, что расходится не больше чем на 10 см |
| `--fit 0` | строить по фактической съёмке |
| `--profile да` / `--profile нет` | с профилем или без (только план и ведомость) |
| `--start N` | номер точки обечайки колодца, с которого начинается ход |
| `--names "НК-1,НК-2,…"` | имена колодцев, если проекта нет |

Рядом с ИЧ всегда появляется `ИЧ — расхождения.csv` (открывается в Excel): проект, съёмка, разница, что пошло на чертёж, пометка («совпадает», «принято по проекту», «по факту, больше допуска»). Отчёт пишется в обоих режимах — и под проект, и по факту.

Быстрый просмотр результата без AutoCAD:

```
python3 preview.py ИЧ.dxf ИЧ.png
```

## Коды точек

| Код | Доп. код | Что это |
|---|---|---|
| 476 | `_kks-2`, `_kks-3`, `_2,99x1,60` | обечайка, центр колодца; тип или размер камеры |
| 47 | `_np` / `_vp` | низ / верх плиты |
| 99 | — | дно колодца |
| 478 | `_1d110`, `_24d125` | верх трубы; число и диаметр труб |
| 4028 | `_1d325` | верх футляра; участок — футляр, если оба конца 4028 |

Связи: `..` — с предыдущей точкой, `..N` — с точкой N, `..,N` — с предыдущей и с N.

## Что считает программа

- Длина пролёта — от центра до центра колодца (по точкам обечайки).
- Глубина колодца = обечайка − дно; Нг. = обечайка − низ плиты; высота камеры = низ плиты − дно.
- Верх трубы в футляре: одна труба лежит на дне футляра (`верх футляра − D + стенка + d`).
- Профиль: 1:500 по горизонтали, 1:100 по вертикали; условный горизонт — дно − 1 м.

## Сверка с проектом

Колодцы проекта и съёмки сопоставляются по порядку вдоль трассы; направление хода выбирается по лучшему совпадению отметок. Если число колодцев разное, это пишется в отчёт.

При подгонке на ИЧ идут проектные значения, если расхождение не больше допуска; остальные — по съёмке. Подгоняются отметки обечаек, дна, горловины, верха трубы на входе и выходе, длины пролётов и футляров. Промежуточные точки трубы и план остаются по съёмке.

## Ограничения прототипа

- Нет ответвлений трассы; нет чтения `.are` / `.pco`.
- Проект заносится в JSON вручную (чтение из ИД — в планах).
- Колодец на плане — прямоугольник по типоразмеру; выноски — текст с линиями; тип линии сплошной.
- Нет линии земли, покрытия, пересекаемых коммуникаций (нужна геоподоснова), развёрток колодцев, рамки и штампа.

Справочник типов колодцев — `WELL_TYPES` в начале `ich.py` (сейчас ККСр-2 и ККС-3).
